## 快速验证命令

```bash
# 1. 健康检查
curl http://localhost:5000/health

# 2. Prometheus 指标
curl http://localhost:5000/metrics

# 3. 登录测试
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"employeeNo":"test","password":"test123"}'

# 4. 检查日志文件
ls -la logs/

# 5. 检查日志内容（脱敏验证）
grep -i "password\|token\|secret" logs/webapi-*.log | head -5
```
