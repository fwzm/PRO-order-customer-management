## 系统概述

PRO系统是一个订单与客户管理系统，主要功能包括：
- 管理客户信息和订单全生命周期
- 订单模板和复制，快速创建订单
- 配送分配（手动/批量/自动）
- 库存管理和变动日志
- 收款登记与多对多核销
- 应收账款和账龄分析
- 数据质量检测
- 审计日志和操作追溯
- 操作撤销与恢复

### 系统要求
- Windows 10/11 操作系统（桌面客户端）或现代浏览器（Web端）
- 网络连接正常
- 推荐分辨率：1920x1080

## 登录与退出

### 登录系统
1. 打开PRO系统
2. 输入工号和密码
3. 点击"登录"
4. 首次登录建议修改密码

### 退出系统
- WPF客户端：点击右上角"×" → 选择"最小化到托盘"或"退出"
- Web端：点击右上角头像 → "退出登录"

### 修改密码
1. 系统设置 → 个人设置 → 修改密码
2. 输入原密码和新密码
3. 确认

**密码要求：** 至少8位，包含大小写字母和数字

## 手机端使用

PRO 手机端以 PWA 形式提供。管理员部署好手机端地址后，用户可以直接用浏览器访问，也可以添加到手机桌面。

### 安装到手机桌面

**Android / Chrome：**
1. 用 Chrome 打开管理员提供的 PRO 地址。
2. 点击右上角菜单。
3. 选择"安装应用"或"添加到主屏幕"。
4. 回到手机桌面，点击"PRO系统"图标打开。

**iPhone / Safari：**
1. 用 Safari 打开管理员提供的 PRO 地址。
2. 点击底部分享按钮。
3. 选择"添加到主屏幕"。
4. 回到手机桌面，点击"PRO系统"图标打开。

### 手机端适合处理什么

- 查看工作台、今日待办和告警。
- 查询客户、订单、产品和配送状态。
- 外出时快速查看客户档案和订单详情。
- 轻量录入或修改业务信息。

大量批量操作、复杂报表和系统配置仍建议在电脑端完成。

### 数据是否与电脑端互通

互通。手机端通过 WebApi 访问同一套数据库，电脑端新增的客户、订单、库存和收款记录，手机端刷新后即可看到；手机端提交的数据也会进入同一套业务系统。

## 订单管理

### 新建订单
1. 点击"订单" → "新建订单"
2. 搜索并选择客户
3. 填写配送地址（可从客户地址自动填充）
4. 添加产品：搜索产品 → 输入数量 → 输入单价
5. 点击"保存"

**注意：** 数量×单价自动计算金额，支持草稿保存

### 复制订单
1. 在订单列表中找到要复制的订单
2. 点击"复制"按钮
3. 系统自动创建草稿订单，包含原订单的客户、产品、地址
4. 修改需要变更的信息（数量、地址等）
5. 保存订单

**说明：** 复制的订单备注会标注"克隆自订单 xxx"

### 使用订单模板

**保存模板：**
1. 在订单列表中选择一个订单
2. 点击"保存为模板"
3. 输入模板名称
4. 确认保存

**从模板创建订单：**
1. 点击"从模板创建"
2. 选择模板（支持热门模板排序）
3. 系统自动填充客户、产品、地址
4. 根据需要修改
5. 保存

**模板管理：**
- 热门模板：按使用次数排序显示
- 启用/停用：暂时不用的模板可停用（软删除）
- 删除：停用的模板可删除

### 订单状态说明
| 状态 | 说明 | 可转换到 |
|------|------|----------|
| 草稿 | 未确认的订单，可修改 | 待分配、已取消 |
| 待分配 | 已确认，等待分配配送员 | 已分配、已取消 |
| 已分配 | 已分配配送员 | 配送中、待分配、已取消 |
| 配送中 | 配送员正在配送 | 已完成、配送失败 |
| 配送失败 | 配送未成功 | 待分配、已分配、已取消 |
| 已完成 | 配送完成 | — |
| 已取消 | 订单已取消 | — |

### 配送分配

**手动分配：** 选择订单 → 分配配送员 → 确认

**批量分配：** 勾选多个订单 → 批量分配 → 选择配送员 → 确认

**自动分配：** 进入配送管理 → 自动分配 → 系统按算法自动分配（支持 region_load_distance 算法）

### 批量操作
1. 勾选多个订单
2. 点击"批量操作"
3. 选择操作类型（分配配送员/修改状态）
4. 填写必要信息（如取消原因）
5. 确认

**批量结果说明：**
- 系统会逐条校验订单状态流转规则，合法订单继续处理，非法订单自动跳过。
- 操作完成后会显示成功数量、失败数量，以及失败订单号和失败原因。
- 已取消、已完成等终态订单不会被批量确认或重新分配。
- 如果部分成功、部分失败，成功订单会保留处理结果，失败订单不会被覆盖状态。

### 订单筛选
- 按状态：选择订单状态
- 按收款状态：未收款/部分收款/已收款/法务处理
- 按时间：选择日期范围
- 按关键词：搜索订单号或客户名

### 草稿有效期
- 新建草稿订单默认有效期为 30 分钟。
- 管理员可在"系统设置 → 应用设置 → 订单草稿"中调整有效期。
- 配置为空、不是数字或小于等于 0 时，系统自动按 30 分钟处理。

### 全局搜索
- 顶部搜索框支持客户、订单、产品、配送员搜索。
- 支持中文精确匹配、中文包含匹配和拼音首字母搜索。
- 示例：输入 `zs` 可搜索"张三"等首字母匹配结果。

## 客户管理

### 查看客户列表
进入"客户管理" → "客户列表"，列表显示：
- 客户名称、编号
- 客户类型（大客户/细分客户）
- 手机号、地址
- **最近下单时间**：最后一次下单的日期
- **累计金额**：所有已完成订单的总金额
- **应收余额**：尚未收款的金额
- **待配送状态**：是否有配送中的订单

### 新建客户
1. 点击"新建客户"
2. 填写信息：
   - 客户名称（必填）
   - 客户类型：大客户/细分客户
   - 手机号（选填）
   - 省份/城市/区县（选填）
   - 详细地址（选填）
   - 法人代表（选填）
3. 点击"保存"

**注意：** 客户编号自动生成（格式：K+年月日+分公司编号+递增序号）

### 编辑客户
1. 在客户列表中点击客户名称
2. 修改需要变更的信息
3. 保存

### 客户查重
1. 客户管理 → 客户查重
2. 输入查询条件（手机号/名称/地址/法人）
3. 系统自动检测重复客户：
   - 手机号相同
   - 名称+地址相似
   - 法人+手机号相同

### 合并客户
1. 发现重复客户后
2. 选择主客户（保留的客户）
3. 选择要合并的客户（可多选）
4. 确认合并

**注意：** 合并后，被合并客户的订单转移到主客户，原客户标记为"已合并"。只能合并同分公司客户。

### 识别长期未下单客户
- 客户列表支持按"最近下单时间"排序
- 可筛选出超过30天未下单的客户
- 用于客户维护和回访

## 库存管理

### 查看库存
1. 进入"库存管理"
2. 查看产品库存列表
3. 支持按产品名称、SKU搜索

### 库存变动日志
1. 点击"库存变动日志"
2. 查看每次库存变化记录，包含：
   - 产品名称和SKU
   - 变动前数量 → 变动后数量（变动量）
   - 变动类型（订单创建/订单取消/手动调整）
   - 变动原因
   - 关联订单号
   - 操作人和操作时间
3. 支持按产品、变动类型、时间范围筛选

### 订单对库存的影响
- **创建订单：** 库存自动扣减，日志记录"OrderCreate"
- **取消订单：** 库存自动恢复，日志记录"OrderCancel"
- **订单状态变更：** 配送失败不恢复库存，取消才恢复

### 手动调整库存
1. 库存管理 → 手动调整
2. 选择产品 → 输入目标数量 → 填写调整原因
3. 确认

**注意：** 手动调整会记录在变动日志中（类型：ManualAdjust）

### 批量盘点
1. 库存管理 → 批量盘点
2. 输入多个产品的实际库存
3. 确认盘点
4. 系统自动计算差异并记录日志

### 库存变动统计
1. 库存管理 → 变动统计
2. 选择时间范围
3. 查看：按变动类型汇总、产品变动排行

## 收款管理

### 收款登记
1. 进入"收款管理" → "新增收款"
2. 选择订单或客户
3. 输入收款金额
4. 选择支付方式：现金/银行转账/微信/支付宝/支票/其他
5. 填写交易号（选填）
6. 填写备注（选填）
7. 保存

**说明：**
- 全额收款后，订单收款状态自动变为"已收款"
- 部分收款后，订单收款状态为"部分收款"
- 支持上传附件

### 批量收款
1. 收款管理 → 批量收款
2. 选择多个订单
3. 分别输入收款金额
4. 保存

### 收款核销
一笔收款可以分多笔核销到不同订单，支持部分核销。

1. 在收款列表中选择一笔收款记录
2. 点击"核销"
3. 选择一个或多个订单
4. 分别输入核销金额
5. 确认核销

**核销规则：**
- 核销总金额不能超过收款金额
- 已核销金额自动累加
- 核销后订单收款金额同步更新

### 查看核销明细
1. 在收款记录上点击"查看核销明细"
2. 查看该笔收款已核销到哪些订单，各核销多少

### 收款统计
1. 收款管理 → 收款统计
2. 选择时间范围和分公司
3. 查看：
   - 总收款金额和笔数
   - 按支付方式分类统计
   - 每日收款趋势
   - 客户收款排行

### 删除收款（退款）
1. 选择收款记录 → 删除
2. 填写删除原因
3. 确认

**注意：** 删除收款会回退订单的收款金额，关联的核销记录也会处理。

## 应收账款与账龄分析

### 查看应收账款
1. 进入"财务管理" → "应收款"
2. 列表显示：客户、应收余额、最后下单时间等
3. 支持筛选：按客户、分公司、业务员、最低余额
4. 支持排序：按余额、账龄等

### 客户应收明细
1. 在应收列表中点击客户
2. 查看该客户所有未收款的订单明细
3. 包含每笔订单的金额、已收金额、未收金额

### 账龄分析
1. 财务管理 → 账龄分析
2. 选择筛选条件（客户/分公司/业务员）
3. 查看分析结果：
   - **0-30天：** 近期应收
   - **31-60天：** 需关注
   - **61-90天：** 需催收
   - **90天以上：** 高风险
4. 各账龄段显示金额和占比

## 数据质量检测

### 生成数据质量报告
1. 系统设置 → 数据质量
2. 选择分公司（可选，总部管理员可查看全部）
3. 点击"生成报告"

### 报告内容
报告包含以下维度：

**客户质量：**
- 客户总数
- 重复客户数量
- 空手机号客户数
- 空地址客户数
- 企微未绑定客户数
- 不活跃客户数
- 客户质量评分

**订单质量：**
- 订单总数
- 过期草稿数
- 长期待处理订单数
- 未结算完成订单数
- 订单质量评分

**产品质量：**
- 产品总数
- 重复SKU数
- 负库存产品数
- 产品质量评分

**综合评分和等级**

### 修复数据问题
- 重复客户：点击"合并"按钮合并
- 空数据：手动补全客户信息
- 长期未下单：标记为非活跃客户

## 审计日志与操作追溯

### 查看操作日志
1. 系统设置 → 审计日志
2. 查看所有关键操作的记录
3. 支持筛选：
   - 按对象类型（订单/客户/产品等）
   - 按对象ID
   - 按变更字段
   - 按操作类型（创建/更新/删除/状态变更/核销等）
   - 按操作人
   - 按分公司
   - 按时间范围

### 查看状态变更历史
1. 在订单详情中 → 查看"状态历史"
2. 显示每次状态变更的：
   - 变更前状态 → 变更后状态
   - 操作人
   - 变更时间
   - 变更原因

### 查看收款状态历史
1. 在订单详情中 → 查看"收款状态历史"
2. 显示收款状态的变更记录

### 状态回滚
1. 在审计日志中 → 选择需要回滚的操作
2. 点击"状态回滚"
3. 填写回滚原因（必填）
4. 确认回滚

**注意：** 回滚操作也会被审计日志记录

## 常见问题

### Q: 登录时提示"密码错误"怎么办？
**A:** 检查工号和密码是否正确（注意大小写）。连续5次失败后账号锁定，联系管理员解锁。

### Q: 订单保存失败怎么办？
**A:** 检查是否选择了客户、是否添加了产品、是否有产品库存不足。查看错误提示信息。

### Q: 库存数量不准确怎么办？
**A:** 查看库存变动日志确认异常，执行库存盘点，联系管理员处理。

### Q: 收款登记后订单状态没更新？
**A:** 检查收款金额是否全额。部分收款订单状态显示"部分收款"，全额收款才变为"已收款"。

### Q: 如何恢复误删的数据？
**A:** 关键操作支持撤销（有效期内）。也可通过状态回滚恢复。重要操作前建议确认。

### Q: 导出失败怎么办？
**A:** 在导出历史中点击"重试"。减少导出数据量（缩小筛选范围）。联系管理员。

### Q: 系统运行缓慢怎么办？
**A:** 检查网络连接。减少同时打开的页面。联系管理员检查服务器状态。

### Q: 如何查看某个订单的完整变更记录？
**A:** 在订单详情中查看"状态历史"和"修改记录"，或在审计日志中按订单ID查询。
